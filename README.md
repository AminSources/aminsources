## 🚀 Featured Project

### Hamsafar

**Hamsafar** is a Flutter application designed to make planning and coordinating short trips between friends easier.

The project focuses on solving practical problems before and during a trip, including:

* 🗓️ Coordinating everyone's free time
* 🗳️ Voting on departure times
* 🎒 Managing the tools and items each person brings
* 💰 Splitting trip expenses
* 📋 Assigning responsibilities
* 📜 Managing group rules

**Stack:** Flutter · Dart · Supabase · PostgreSQL
